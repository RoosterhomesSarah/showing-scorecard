# Your clients

One folder per buyer. Created for you as you go, so you should not need to make one
by hand.

```
clients/
  henderson/
    criteria.md                     what they told you they want
    2026-03-14-scorecard.html       the tour
    2026-03-14-results.md           what they sent back
    2026-04-02-scorecard.html       a later tour, same buyer, new file
```

The date is in the filename so a second tour never overwrites the first, and so you can
see how a buyer's list moved over a month.

**Nothing in here is ever committed or shared.** Your clients stay on your computer. (The one
thing that goes online is a scorecard page, as a copy you upload yourself.)
